# 架构说明

## 运行流程

1. 用户启动 Antigravity。
2. 用户级 LaunchAgent 启动 Antigravity 自带的 Node 运行环境。
3. 助手读取 Antigravity 的本机调试端口，只连接本机页面目标。
4. 在页面中安装中文翻译层，并监听后续动态渲染的界面。
5. 暂停或卸载时，翻译层恢复原文并移除用户级助手文件。

## 为什么不修改 ASAR

直接替换官方 ASAR 会扩大安装范围，可能影响官方更新、完整性校验和代码签名。本项目把翻译逻辑放在外部助手中，牺牲一部分覆盖范围，换取更小的改动面和更容易的恢复流程。

## 词库组成

- `translations.json`：固定界面词条。
- `translator.js` 中的动态规则：处理时间、令牌数量、执行状态、权限范围和带命令的确认提示。
- 保护选择器：跳过代码、终端、输入和用户内容。
